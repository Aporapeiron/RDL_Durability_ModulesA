# 翻訳後の暫定操作案

外部手法・旧分類・既存操作を、RDL の T2 操作として一度翻訳した暫定案を置く。

ここに置く文書は、まだ正式な T2 モジュールではない。ただし、旧素材そのものではなく、RDL の語彙と代謝プロセスに接続する形へ一段翻訳済みの候補として扱う。

## 現在の候補

| 文書 | 位置づけ |
|---|---|
| `多重SILN操作_比較・配置系メモ_v0.1.md` | 旧「比較分析」を、検査済みの複数SILNを並べ、対応関係・破断条件・残存構造をもとに大きな関係ネットワーク上へ配置する血肉化系候補として翻訳した暫定案。 |
| `シミュレーション破断検査_RDL翻訳メモ_v0.1.md` | SILNを時間・条件・入力のもとで動態化し、揺らし破断検査・履歴生成・破断探索・残存観測を仮想的に実行する破断検査環境候補として翻訳した暫定案。 |

## 位置づけ

```text
旧分類・外部手法
↓
RDL語彙への翻訳
↓
翻訳後の暫定操作案
↓
実運用
↓
有効範囲・破断条件・再構成先の記録
↓
正式モジュール候補
```

## 注意

耐久検査に直接属するものは `耐久検査/翻訳後の暫定ツール案/` に置く。

ここには、耐久検査だけでは収まらない T2 操作候補を置く。
