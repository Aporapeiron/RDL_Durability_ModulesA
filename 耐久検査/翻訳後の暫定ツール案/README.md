# 翻訳後の暫定ツール案

既存の手法や外部概念を、RDL の耐久検査で扱える形へ一度翻訳した暫定ツール案を置く。

ここに置く文書は、まだ正式な T2 モジュールではない。ただし、`_暫定/` にある旧素材・未整理案とは異なり、RDL の語彙と操作へ一段翻訳済みの候補として扱う。

## 現在の候補

| 文書 | 位置づけ |
|---|---|
| `揺らし破断検査_RDL翻訳メモ_v0.2.md` | 感度分析とストレステストを、関係・条件を揺らして耐久地形を写す同型操作として統合した暫定ツール案。 |
| `履歴破断検査_RDL翻訳メモ_v0.1.md` | 旧「履歴分析」と「統計的破壊法」を統合し、観測履歴に現れる E の分布・偏り・再現性・残留から破断条件を逆向きに読む暫定ツール案。 |
| `除去破断検査_RDL翻訳メモ_v0.1.md` | 旧「ノックアウト実験」を、関係・要素を離散的に除去して維持域・代替関係・最小残存骨格・破断条件を調べる暫定ツール案。 |
| `境界破断検査_RDL翻訳メモ_v0.1.md` | 旧「境界ズラしテスト」を、有限境界 B を変化させて SILN を再生成し、境界依存性・境界耐久範囲・破断境界を調べる暫定ツール案。 |
| `関係制約破断検査_RDL翻訳メモ_v0.1.md` | 関係仮設群から制約・保存条件・両立条件を導き、観測・構成・変換が許容空間を外れるかを見ることで関係集合の破断を調べる暫定ツール案。 |

## 位置づけ

```text
外部手法・旧素材
↓
RDL語彙への翻訳
↓
翻訳後の暫定ツール案
↓
実運用
↓
耐久証明書・破断条件・有効範囲の記録
↓
正式モジュール候補
```

## 昇格条件

- 対象と境界 B が明示できる
- 入力、操作、出力が説明できる
- 維持域、変形域、遷移域、破断境界を記録できる
- 破断後にも残る関係を抽出できる
- 実例で運用されている
