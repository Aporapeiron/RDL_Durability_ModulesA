# 耐久検査

RDL Modules における T2 代謝機構としての耐久検査・破壊検査系文書群。

現時点では、ここにある文書はすべて暫定である。実際の検査運用で十分に使われ、入力・出力・破断条件・残存構造・耐久証明書が蓄積されるまでは、正式な実用文書としては扱わない。

## 現在の配置

| フォルダー | 位置づけ |
|---|---|
| `翻訳後の暫定ツール案` | 外部手法や旧素材を RDL 語彙へ一度翻訳した暫定ツール案。正式モジュールではないが、旧素材より一段進んだ候補。 |
| `試運転` | 翻訳後の暫定ツール案を実対象へ一巡適用し、操作として回るかを確認する試行記録。 |
| `_暫定/コア候補` | 将来、耐久検査の中核手順になりうる文書候補。 |
| `_暫定/ツール候補` | 個別の検査道具になりうる文書候補。 |
| `_暫定/試行例候補` | 応用例・検査例になりうる文書候補。 |
| `_暫定/背景・思想` | 前提・思想・教育モデルなどの参照候補。 |
| `_暫定/旧版` | 旧体系・重複・履歴確認用の文書。 |

## 原則

- すべて暫定として扱う。
- 実際に使ってから昇格を判断する。
- 昇格条件は、対象、境界 B、入力、出力、破断条件、残存構造、耐久証明書が記録されること。
- 重複した出自別フォルダーは残さず、必要な情報は `_暫定/` 内の分類で保持する。
