# 耐久検査 実用検査文書

このフォルダーは、`耐久検査` に一旦集めた破壊学系文書のうち、実際の検査運用に使う文書だけを抽出した作業セットである。

## 採用文書

| 順 | 文書 | 役割 |
|---|---|---|
| 00 | `00_限界空間的破壊ゲート.md` | 検査ツール採用前の前処理。ツール自身が絶対化・閉域化・単一解化していないかを見る。 |
| 01 | `01_構造破壊学_出発ツール群設定指針.md` | 対象・境界・借用ツール・耐久証明書を設定するための実用手順。 |
| 02 | `02_出発ツール例_統計的破壊法.md` | 残差・外れ値・条件依存性から破断条件や新構造候補を読む個別ツール例。 |
| 03 | `03_圏論的構造破壊検査プロトコル.md` | 可換性・合成可能性・関手保存性などから翻訳破断や接続破断を検査するプロトコル。 |
| 04 | `04_構造破壊学ツールボックス_v2.md` | 前提抽出・断面変換・破壊検出・残存移植解析をまとめたツール一覧。 |

## 外した文書の扱い

以下は重要だが、実用検査の直接手順ではないため、この作業セットには含めない。

- 背景・思想説明
- 教育モデル
- 個別応用例
- 旧版重複
- 具体例としての耐久証明書

必要に応じて、親フォルダー側の出自別フォルダーから参照する。
